    Import Images¶

    Widget: Open Files¶

    Open a file and return a napari layer.
    • File type: None
    • File path: Select one or more files to import; multiple files are imported as one time series, in alphanumeric filename order.
    • Layer name: Define the name of the output layer, default is either image or label.
    • Layer type: Select the type of input you are loading.
    • Stack layout: t for time, c for channel, xyz for dimensions, e.g.: tzyxc will be reshaped to [T][C][Z]YX. Invert an axis by adding `-` infront of the letter. Truncate the data before importing with a slice after the letters, e.g. txyz[:3,:,:]: the entries follow the layout as written, before reordering, an integer drops its axis. While importing multiple files, the stack layout must start with a 'T'.

    Time Series¶

    Importing time series data is supported in PanSeg. If your file has a time dimension, just load it and specify the time dimension in the stack layout as t. Otherwise, you can load a time series by selecting multiple files during the import. The files are stacked in alphanumeric filename order, so a2.tif comes before a10.tif. When importing from multiple files, slicing is not supported.

    Stack Layout¶

    PanSeg does its best to guess the stack layout of the file you are loading, but always make sure this guess is correct. The layout can be any permutation of the letters t, c, z, y, x that match your file, so a 3D time series gets prefilled as TZYX.

    You can invert an axis by prepending it with a minus. Also, slicing is supported: slice the data by appending, e.g. tczxy[:10,2] to only load the first ten frames of the third channel.
    The slicing functionality can also be used for cropping already during the import (CXYZ[1,:50,:50,:10]).
